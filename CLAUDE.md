# Portfolio — Aya Jalid

Site portfolio personnel. HTML/CSS statique, pas de framework, pas de build tool.

## Structure

```
index.html              page d'accueil (hero, grille projets, à propos, contact)
projet-*.html           pages détail de chaque projet (10 projets)
style.css               feuille de style unique (toutes les pages)
images/                 assets organisés par projet
cv-aya-jalid.pdf        CV téléchargeable
```

## Conventions

- Pas de JavaScript framework — HTML/CSS purs
- Une seule feuille de style partagée (`style.css`)
- Langue : français
- Typographie : Poppins (titres), Lato (textes)
- Responsive : mobile-first, breakpoints dans `style.css`

## Contenu

- **Auteure** : Aya Jalid, architecte designer — Paris
- **Disponibilité** : CDI à partir de juillet 2026
- **10 projets** : PUUL, Tercel, CrousLab, Design Maker, Design Week, Jerada, Reinventer Paris, Siège Marque Inter, Stage CrousLab, Vivre l'Espace

## Workflow

- Modifications confirmées par l'utilisateur avant application
- Commits manuels après validation des changements
- Repository GitHub connecté sur la branche `main`
